# RHYTHM MASTA

Mrs. GREEN APPLE 팬이 혼자 즐기려고 만든 웹 리듬게임이에요. 7키(6키+스페이스) / 4키, 모바일 터치를 지원해요.
노래 파일은 들어 있지 않고, 유튜브 공식 플레이어로 뮤직비디오를 재생해요.

## 바로 하기 (웹)
**https://seongyoru.github.io/rhythm-masta/** 에 접속하면 PC든 휴대폰이든 어디서나 바로 할 수 있어요. 설치나 실행할 파일이 없어요.
- 휴대폰으로 열면 4키 터치 모드가 기본이에요.
- 최고 기록, 설정, 추가한 곡은 그 기기의 브라우저에 저장돼요(기기끼리 공유되지 않아요).

## 내 PC에서 실행 (오프라인용)
**`start.bat`** 을 더블클릭하세요. 작은 검은 창이 뜨고 브라우저에서 게임이 열려요.
- 게임하는 동안 검은 창은 닫지 마세요. 닫으면 게임 서버가 꺼져요.
- 같은 와이파이의 휴대폰에서 하고 싶으면 `start-mobile.bat` 을 쓰세요 (아래 "모바일에서 하기").

## 유튜브 곡
노래 파일을 내려받지 않고 **유튜브 공식 플레이어로 영상을 재생**해요. 게임 중에는 영상이 배경에 흐리게 깔려요.

1. 곡 목록의 **유튜브** 버튼을 누르고 공식 채널 영상 주소를 붙여넣은 뒤 **불러오기**를 누르세요.
2. 제목과 아티스트는 자동으로 채워져요. 필요하면 고치면 돼요.
3. **BPM과 첫 박**을 맞춰야 해요. 게임이 유튜브 소리를 직접 분석할 수 없기 때문이에요.
   - ▶ 재생을 누르고, 노래가 시작되는 첫 박부터 박자에 맞춰 `T` 키를 8번 이상 누르면 자동으로 계산돼요.
   - **메트로놈**을 켜면 맞춘 박자대로 딸깍 소리가 나요. 노래와 맞는지 확인할 수 있어요.
   - `◀ 1박` / `1박 ▶` 와 "지금 위치를 첫 박으로" 버튼으로 미세하게 조정할 수 있어요.
4. **저장하고 채보 만들기**를 누르면 BPM에 맞춘 EASY / NORMAL / HARD 채보가 만들어져요.

곡 목록은 브라우저에 저장돼요. 곡 설정과 삭제는 곡 상세 화면의 버튼으로 할 수 있어요.

> 참고
> - 일부 공식 영상은 채널 설정으로 외부 재생이 막혀 있어서 재생되지 않을 수 있어요.
> - 광고가 나오면 광고가 끝난 뒤에 게임이 시작돼요.
> - 템포가 바뀌는 곡은 BPM 자동 채보가 어긋날 수 있어요. 이럴 땐 녹화 채보를 써 주세요.
> - 영상을 흐리게 하고 그 위에 게임을 띄우는 방식은 개인 플레이 용도로만 쓰세요. 유튜브 정책상 공개 배포는 권장되지 않아요.

## 채보 녹화 (내 채보 만들기)
곡 상세 화면의 **● 채보 녹화** 버튼을 누르면, 지금 고른 난이도의 채보를 직접 쳐서 만들 수 있어요.
- 노래를 들으며 키를 치면 친 그대로 노트가 돼요. 길게(0.3초 이상) 누르면 롱노트가 돼요.
- BPM이 있는 곡은 16분음표 박자에 맞춰 자동으로 정리돼요.
- 중간에 `Esc` → **여기까지 녹화 저장**(`S`)으로 끝낼 수 있어요. 곡이 끝나면 자동으로 저장돼요.
- 녹화한 채보는 난이도 카드에 "내 채보"로 표시돼요. **자동 채보로 되돌리기**로 원래대로 돌릴 수 있어요.
- 녹화는 유튜브 곡, 음악 파일, 데모곡 모두에서 쓸 수 있어요.

## 조작
메뉴 설정의 **키 모드**에서 7키 / 4키를 고를 수 있어요. 모바일로 열면 4키가 기본이에요.

| 모드 | 키 |
|---|---|
| 7키 | A (ㅁ) · S (ㄴ) · D (ㅇ) · **SPACE** · L (ㅣ) · ; · ' |
| 4키 | D (ㅇ) · F (ㄹ) · J (ㅓ) · K (ㅏ) |

- 한/영 상태와 상관없이 물리 키 위치로 인식해요.
- **키 바꾸기 (PC):** 설정의 **⌨ 키 바꾸기**에서 레인을 누른 다음 원하는 키를 누르세요. 이미 쓰는 키를 고르면 두 레인의 키가 서로 바뀌어요. 4키와 7키는 따로 저장되고, **기본값으로** 버튼으로 되돌릴 수 있어요.
- 메뉴: `↑↓` 곡 선택 · `←→` 난이도 · `Enter` 시작
- 게임 중: `Esc` 또는 왼쪽 위 ⏸ 버튼으로 일시정지 · `↑↓` 스크롤 속도
- 일시정지/결과: `R` 다시하기 · `Q`/`Esc` 곡 선택
- **곡 미리듣기:** 곡을 고르면 그 곡의 후렴(가장 신나는 구간)이 15초 정도 흘러나와요. 설정에서 끌 수 있어요.
- 최고 기록과 녹화 채보는 4키 / 7키 따로 저장돼요.

## 모바일에서 하기
1. PC에서 **`start-mobile.bat`** 을 더블클릭하세요.
2. 검은 창에 나오는 **`On your phone: http://192.168.x.x:5180/`** 주소를 휴대폰 브라우저(크롬/사파리)에 입력하세요.
3. 휴대폰과 PC가 **같은 와이파이**에 연결돼 있어야 해요. 처음 실행할 때 Windows 방화벽 창이 뜨면 **개인 네트워크 허용**을 눌러 주세요.
- 화면의 레인을 터치해서 쳐요(여러 손가락 동시 터치 가능). 건반에는 키 글자 대신 점만 표시돼요.
- 모바일에서는 🎧 자동 맞추기(탭 소리 공유)는 쓸 수 없어요.
- 게임하는 동안 PC의 검은 창은 닫지 마세요.

## 곡 추가

## 샘플 곡 : Mrs. GREEN APPLE 20곡 (실측 채보)
공식 채널 뮤직비디오 조회수 상위 20곡이 들어 있어요. 곡을 고르고 바로 플레이하면 돼요.

| 곡 | BPM(실측) | 곡 | BPM(실측) |
|---|---|---|---|
| インフェルノ | 185 | ロマンチシズム | 125.5 |
| ライラック | 150 | StaRt | 190 |
| 青と夏 | 185 | クスシキ | 138 (구간마다 박 위치가 바뀜) |
| 僕のこと | 160 | ダーリン | 135 |
| ダンスホール | 110 | lulu. | 175 |
| Soranji | 156 | Magic | 117.5 |
| ケセラセラ | 115 | WanteD! WanteD! | 160 |
| ビターバカンス | 132.26 | familie | 191 |
| Love me, Love you | 130 | breakfast | 122 |
| CHEERS | 133 | ナハトムジーク | 146.25 |

**어떻게 만들었나요**
- 각 MV 음원을 임시로 받아 곡 전체를 분석했어요. BPM은 0.02 단위까지 재고, 곡 전체에서 박자가 밀리지 않는지 구간별로 확인했어요. 분석 후 음원은 삭제했어요.
- BPM 데이터베이스(songbpm.com) 값과 비교했더니 몇 곡은 달랐어요. 예를 들어 インフェルノ는 DB에 92지만 실제로는 185(두 배 박자)였어요. 게임에는 실측값을 넣었어요.
- MV 앞부분의 대사나 효과음은 빼고, 박자에 맞는 연주가 시작되는 곳부터 채보를 넣었어요.
- 노트는 실제로 소리가 나는 위치에 놓이고, 그 구간의 16분음표 격자에 맞춰 정리돼요.
- 게임에는 노래 파일 없이 분석 데이터(`js/songdata.js`)만 들어 있어요.

**채보 설계**
- 마디마다 곡의 세기를 보고 노트 수를 정해요. 벌스는 가볍고, 후렴은 촘촘해요.
- 킥은 스페이스, 스네어는 1·5번 레인, 하이햇은 2·4번 레인으로 보내요. 같은 소리는 같은 자리에 와서 손에 익어요.
- 양손을 번갈아 쓰고, 같은 레인을 연타하는 건 피했어요.
- 16분음표 연타는 계단, 트릴, 롤, 지그재그 패턴으로 만들었어요.
- 강한 정박에는 대칭 동시치기를 넣었어요(HARD 후렴은 3키).
- 길게 이어지는 소리는 롱노트로 만들었어요. 후렴 첫박은 "한 손 롱노트 + 다른 손 연타"로 만들었어요.
- 난이도는 EASY Lv3~4(정박 위주), NORMAL Lv6~7(8분), HARD Lv12~15(16분, 동시치기)예요.

샘플 곡이 필요 없으면 곡 상세 화면의 **삭제** 버튼으로 숨길 수 있어요. 직접 추가한 유튜브 곡은 **🎧 자동 맞추기**나 탭으로 첫 박을 맞춰요(위 "유튜브 곡" 참고).

## 타격음
메뉴 설정의 **타격음**에서 고를 수 있어요. 키를 누르는 순간 바로 소리가 나고, 모든 소리에 짧은 방 울림(잔향)과 스테레오 퍼짐이 들어 있어요.

| 종류 | 소리 |
|---|---|
| osu! 느낌 (기본) | 짧고 단단한 '탁' |
| 태고 느낌 | 4키는 F·J가 '동'(북 가운데), D·K가 '캇'(북 테두리)이에요. 태고의 달인 PC 배치와 같아요. 7키는 안쪽 키와 스페이스가 '동', 바깥 키가 '캇' |
| 리듬 히어로 느낌 | 짧고 경쾌한 '팍' |
| 킥 펀치 | 묵직한 '쿵' |
| 스네어 | '짝' |
| 핸드클랩 | 박수 |
| 림샷 | '딱' |
| 하이햇 | '칫' |
| 내 효과음 파일 | 직접 고른 소리 파일 (아래) |
| 없음 | 소리 없음 |

위 소리들은 실제 게임 효과음 파일이 아니라, 그 느낌이 나도록 직접 합성한 소리예요. 실제 게임 효과음은 저작권이 있어서 이 저장소에 넣지 않았어요.

**내 효과음 파일**
- 갖고 있는 효과음(wav · mp3 · ogg, 5MB 이하)을 직접 쓸 수 있어요. 타격음을 "내 효과음 파일"로 고르면 버튼이 나와요.
- **기본 · 안쪽 레인**에 파일 하나만 넣으면 모든 레인에 그 소리가 나요.
- **바깥쪽 레인** 파일까지 넣으면 안쪽과 바깥쪽 소리가 달라져요. 예를 들어 '동'과 '캇' 파일을 넣으면 태고처럼 쓸 수 있어요.
- 파일은 그 기기 브라우저에만 저장되고, GitHub에는 올라가지 않아요. PC와 휴대폰은 각각 넣어야 해요.

## 판정
| 판정 | 범위 | 점수 비중 |
|---|---|---|
| PERFECT | ±42ms | 100% |
| GREAT | ±85ms | 70% |
| GOOD | ±130ms | 40% |
| MISS | 그 외 | 0% |

롱노트는 머리 판정 + 끝(손 뗄 때) 판정 2개로 계산합니다. 소리와 노트가 어긋나 보이면 메뉴의 **오프셋**을 조절하거나, 결과 화면의 추천 오프셋을 적용하세요.

## 파일 구성
- `js/audio.js` 오디오 재생 · 타이밍 · 타격음/차임
- `js/skins.js` 스킨 정의 (색 · 노트 스타일 · 배경)
- `js/youtube.js` 유튜브 플레이어 재생 · 싱크 · 탭 템포
- `start.bat` / `serve.ps1` PC에서 실행 (유튜브 재생용 간이 웹서버)
- `start-mobile.bat` / `serve-lan.ps1` 같은 와이파이의 휴대폰에서도 접속할 수 있게 실행
- `js/demo.js` 내장 데모곡 합성 (Neon Pulse, 140BPM)
- `js/chart.js` 음악 분석 · 자동 채보 생성 · 샘플 곡 채보 설계
- `js/songdata.js` 샘플 20곡 분석 데이터 (실측 BPM · 첫 박 · 소리 위치 · 음량)
- `js/autosync.js` 탭 소리를 듣고 BPM · 첫 박 자동 맞추기
- `js/game.js` 판정 · 렌더링 · 이펙트
- `js/main.js` 메뉴 · 입력 · 결과 화면
